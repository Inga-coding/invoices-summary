# Обробка рахунків-фактур (Invoices Report)

Невелика програма на Python для зчитування, валідації та аналізу даних про рахунки з CSV-файлу.

## Що робить програма
* Зчитує дані з файлу `data/invoices.csv` (шляхи будуються незалежно від поточної директорії через `pathlib`).
* Перевіряє коректність даних: відловлює порожні значення, текст замість чисел та від'ємні суми (через власний виняток `InvalidAmountError`).
* Пропускає некоректні рядки з інформативним попередженням, не зупиняючи роботу програми.
* Підраховує загальну суму коректних рахунків та фільтрує рахунки зі статусами «очікується» і «прострочено».
