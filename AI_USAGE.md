
# Використання ШІ 

Під час підготовки застосунку на **Streamlit**, оформлення документації та перевірки працездатності використовувався ШІ-асистент Gemini.

## Які питання ставила
* Як підключити логіку з пакета `app/` і шляхи з `app/config.py` до `streamlit_app.py` без дублювання розрахунків.
* Як організувати фільтри в бічній панелі, картки метрик, таблицю, стовпчикову діаграму та обробку помилок (`st.error` і `st.stop()`) і порожнього результату (`st.warning`).
* Як оформити `requirements.txt`, `README.md` і підготувати проєкт до публікації на GitHub та Streamlit Community Cloud.

## Як перевіряла відповіді
* Запускала застосунок локально через `streamlit run streamlit_app.py` і перевіряла в браузері роботу фільтрів, перерахунок метрик, таблиці, графіка та відображення повідомлень про помилку без traceback.
* Перевіряла консольний запуск через `python main.py` і прогін тестів через `python -m pytest -v`.
* Перевіряла склад файлів у репозиторії через `git status`, щоб до Git не потрапили `.venv/`, `__pycache__/` та службові чи чутливі файли.
